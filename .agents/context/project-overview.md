# Project Overview

## Description
Poker Trainer is a free, open-source 6-max No-Limit Hold'em poker training simulator with intelligent AI opponents.

## Core Mechanics
1. 6-player No-Limit Hold'em cash game simulation with realistic betting mechanics.
2. AI Opponents (Beginner, Intermediate, Advanced, Pro) with distinct playing styles, position-aware strategies, and board texture analysis.
3. Real-time poker statistics tracking and session dashboard.

## Player Objective
Practice and improve poker skills by playing against various AI opponents and analyzing session statistics and hand history.

## Target Platform
- Primary: Desktop Browser
